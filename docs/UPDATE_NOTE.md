# 更新日志 (Update Notes)

## Xilore Uptime Monitor

## 未发布 - 2026-10-11

- **公告与维护**：新增工作区入口、Markdown 编辑与预览、公告生命周期及维护范围选择。
  支持立即或预约、取消、提前结束和延期；公开页将公告与公开维护合并成时间线，
  置顶公告优先，其余按时间倒序；默认显示第一条，按剩余条数展开，公告与维护状态以颜色区分。
  两类历史统一放在服务列表下方，折叠分页，自动刷新保留展开内容；手机使用单列紧凑时间轴。
- **维护执行与统计**：检测、静默和统计排除独立配置，重叠限制分别合并，
  检测历史固定维护标记，全部统计统一排除指定样本；详情图和状态条标记无检测的维护时段。
  维护不改变监控启用状态，公开接口隐藏私有成员和内部说明。
- **维护恢复与通知**：持久化静默前状态和待首检标记，重启后继续处理；
  公告和维护按事件与渠道入队去重，初次失败后最多重试三次，后台展示投递结果。
  新增增量迁移、受控事务、权限校验及只读模式保护，通知默认关闭。
- **页内交互**：确认操作改用支持键盘的页内对话框，错误采用页内提示，
  不使用浏览器原生 `alert` 或 `confirm`。
  公告与维护的新建、编辑改用浮窗，内容区独立滚动，保存和关闭按钮固定在底部；
  点击浮窗外先提示，再次点击才关闭，继续编辑会取消关闭提示，错误直接显示在浮窗内。
- **专项验证**：覆盖可控时间、重叠开关、重启首检、通知替身、隐私、迁移重入和只读保护，
  使用合成数据走通后台创建至公开展示，并检查手机布局、双主题和键盘操作。

- **分组状态条**：管理端与公开页分组标题增加五分钟粒度的历史汇总，
  折叠后仍可见；离线优先于波动和正常，暂停服务不计入，悬浮显示各状态服务数量。
  公开页首次进入只展开当前异常分组，自动刷新保留本次手动选择，不保存跨次浏览偏好；
  顶部摘要分别列出离线、波动数量和服务名称。
- **响应时间统计**：管理端卡片和公开状态页增加最近 24 小时平均延迟、P99，
  详情统计跟随六档时间范围切换。使用完整原始有效响应计算，支持零毫秒，
  超时及无响应不计入；无有效样本显示 `—`，适配手机和深浅主题。
  管理端主要指标按两列两行对齐，SSL 证书和最后检测时间移到独立信息区。
- **低频检测图表**：按检测间隔调整聚合密度，每小时一次的检测在 24 小时视图
  显示 24 个采样点，去除正常等待形成的交替空白条纹。保持完整时间窗口，
  保留真实缺失、离线与波动状态及响应统计；稀疏曲线标出采样点，避免曲线过冲。
- **浅色侧栏**：改用雾白背景、中性文字与蓝紫选中态，品牌图标跟随主题；
  同步桌面与手机导航，深色主题保留原有石墨配色。

- **版本提示与更新日志**：改用 GitHub 公开版本索引，按镜像架构检查更新；后台展示升级标记、
  最新发布说明、检查时间和可展开分页的历史日志。重要更新只提示，Docker 升级由部署者手动完成。
  检查失败保留上次成功结果，支持重新检查；校验版本编码与链接，安全渲染 Markdown。
  公开页仅读取本机版本，远程查询需要登录。镜像发布后由独立作业登记索引，失败可复用元数据重跑。
  发布登记改用通用 POSIX 脚本，不再依赖 jq。
- **概览分组层级**：为管理端监控分组增加独立容器边框、蓝紫标题栏、数量徽标和状态标签，
  卡片与空分组均收纳在所属容器内；明确展开/收起提示，保留折叠动画、键盘操作、
  筛选与刷新后的折叠状态，适配手机双行标题。
- **离线时段展示**：详情图表增加检测状态色带及图例，区分离线、波动与无记录。
  没有响应时间的离线检测仍显示红色时段与明确说明，不再被空态遮盖，也不会伪造为 0 ms；
  悬浮提示包含时段状态、检测次数与响应统计，曲线断开缺失响应的区间，单个有效响应点保持可见。
- **详情加载与图表切换**：固定详情弹窗、趋势图和记录区的布局，首次加载显示骨架占位；
  切换时间范围保留原图并提示当前数据范围，复用图表实例，以淡入替代曲线坐标动画，
  修复采样点数量变化时新增点从底部拉起的跳动。画布脱离内容排版并限制在固定容器内，
  避免尺寸更新影响弹窗滚动布局。取消过期请求，防止快速切换或关闭弹窗后的迟到响应覆盖内容；
  后台刷新保留滚动位置，加载失败保留已有数据并提供重试，空记录与读取失败分别提示。
- **工作区页脚**：固定在视口底部，避免随页面内容高度移动；为正文预留空间，
  并将设置操作栏置于页脚上方，兼容桌面侧栏和手机安全区域。
- **系统设置页面**：侧栏入口改为独立工作区页面，移除设置浮窗；统一选中态、面包屑、
  页面地址和前进后退，桌面使用分类导航与内容双栏，手机显示完整的分类按钮。保留基础、账户、三类通知、
  版本信息与危险操作，以及保存、通知测试、配置清空和历史删除；工作区切换保留表单输入，
  退出登录清除草稿，加载失败提供重试入口。
- **分组管理页面**：侧栏入口改为主内容区页面切换，移除分组管理浮窗；同步选中态、面包屑与地址，
  支持直接打开、刷新和浏览器前进后退。保留新增、改名、拖拽及删除，增加手机/键盘可用的上下移动按钮，
  避免反复进入页面时重复绑定拖拽事件；自动更新监控数量时保留名称编辑输入。
- **管理端配色重设计**：以石墨灰/雾白替换大面积绿色背景，蓝紫色用于导航选中、按钮与关键指标；
  同步登录、安装、弹窗、404 及历史图表，正常状态条降低饱和度，健康概览改为中性色底与状态色提示，
  保留原有布局、动效及功能。
- **公开页密度与分组**：缩减标题和统计区留白，服务改为指标横向对齐的紧凑列表；分组增加独立边框、

## 版本 2.1.0 - 2026-02-09

- **HTTPS/SSL 证书剩余天数**：HTTP 类型监控在检测 HTTPS 目标时自动读取对端证书有效期，计算并存储剩余天数（`monitors.ssl_days_remaining`）；管理页监控卡片与详情弹窗中展示「剩余 N 天」或「已过期」，非 HTTPS 不显示
- **检测与接口**：HTTP 检测的响应时间改为按单次请求计时，避免 HEAD 回退 GET 时两次往返时间累加导致延迟虚高；API 返回监控列表与详情时包含 `ssl_days_remaining`
- **分组状态计算**：管理页与公开状态页中，分组健康/降级/故障状态只统计未暂停的监控，
  已暂停项不参与计算
- **UI 与样式**：全部检测/分组/设置/添加监控/退出等按钮增加 `title` 或图标；超小屏仅保留图标；退出按钮改为带图标；统计卡片文案「24小时平均可用率」简化为「24小时平均」；详情弹窗与监控卡片 SSL 证书展示样式与占位布局
- **CI**：GitLab CI 构建阶段在推送镜像后增加清理步骤，删除本地已推送的带版本号镜像以释放空间
